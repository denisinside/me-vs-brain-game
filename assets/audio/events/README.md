- `bg_calm_loop1.mp3` - Спокійна фонова музика.

- `aaaahhhh_sfx.mp3` - Звуковий ефект крику.

- `failure-trumpets.mp3` - Інший звук невдачі.

## Формат:

- Якість: 128-192 kbps для MP3
- Тривалість: Різна.
